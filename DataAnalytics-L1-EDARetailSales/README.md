# EDA on Retail Sales Data

## Internship
Oasis Infobyte – Data Analytics Internship

## Level
Level 1 – Task 1

## Project Overview
This project performs Exploratory Data Analysis (EDA) on retail sales data to identify sales trends, customer purchasing patterns, and product performance.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data inspection and statistical analysis
- Monthly and quarterly sales analysis
- Customer age and gender analysis
- Top-selling products identification
- Category-wise revenue analysis
- Correlation heatmap
- Data visualisations and observations

## Key Insights
The analysis explores retail sales patterns and customer behaviour to identify useful business insights.

## Recommendations
Actionable recommendations are based on the findings from the exploratory analysis.
